System requirements

  • macOS 14.0 or later
  • Universal build: runs on both Apple silicon and Intel Macs

Quick start

  1. Drag images or a whole folder into the window (or press ⌘O)
  2. Choose an output format and quality in the sidebar; set a size limit if you need one
  3. Press ⌘↩ to start. Results are written next to the originals by default, and every row shows what changed

Frequently asked questions

Which image formats are supported?

It reads eight families — JPG, PNG (including APNG), GIF, WebP, AVIF, BMP, HEIC/HEIF and TIFF — across thirteen extensions (jpg, jpeg, png, apng, gif, webp, avif, avifs, bmp, heic, heif, tif, tiff).

It writes five output options: Original, AVIF, JPEG, WebP or PNG. With Original, each file keeps its own container and Pixtrio picks the encoder to match.

Are my images uploaded anywhere?

No. Pixtrio requests no network entitlement, and every step happens on your Mac. See the privacy policy.

Why didn't some images get smaller?

By default, if a result isn't smaller than the original, Pixtrio keeps the original and discards the result — the row then reads "No gain". That is how you avoid ending up with files bigger than you started with.

If you do want to keep a larger result (to normalise everything to one format, for example), turn on "Keep no-gain results" under Advanced in the sidebar.

I turned on "Replace original" — how do I undo it?

Within the current session, "Restore Originals" in the bottom bar puts the whole batch back. Originals are copied to a local cache before they are overwritten.

That cache is cleared when you quit or close the window, so after that the originals cannot be recovered. It is not a backup.

"Replace original" is off by default, so results are written next to the originals and your originals stay untouched.

Where do the output files go, and what are they called?

Next to each original by default, with a parameter suffix — for example -q55-h5000 for quality 55 and a 5000 px height limit, or -min for plain PNG optimisation. If a name is already taken, Pixtrio adds a number. Your originals are not overwritten.

You can also choose a fixed destination under "Output folder" in the sidebar.

Are ICC profiles and EXIF metadata kept?

They are not written by default, to save size. To keep them, turn on "Keep ICC profile" or "Keep EXIF metadata" under Advanced in the sidebar.

Do animations get flattened into a still image?

When the output is AVIF or WebP, or the original format is kept, animations keep every frame, the per-frame delays and the loop count.

If you explicitly choose JPEG, JPEG has no animation support, so only the first frame is kept — the list warns you before the run starts.

Can the size limit ever enlarge an image?

No. Width and height only ever shrink, up to 32768 px. You can set either one, or both.

Which languages is the interface available in?

Eleven. Light and dark follow the system, and you can also switch manually.

How do I report a bug?

Use the button below to email us, with as much of the following as you can:

Email support

Mac chip (Apple silicon or Intel)

What you did, what you expected, what actually happened
A screenshot, if it is easy to take one

If the problem is specific to one image, a small test image that reproduces it is enough — you do not need to send us your original.
